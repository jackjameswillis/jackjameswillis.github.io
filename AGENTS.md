# AGENTS.md

Instructions and context for AI agents working in this repository.

## What this repo is

This is the personal academic website of **Jack Willis**, hosted on GitHub Pages.
It is a Jekyll site built on the **[al-folio](https://github.com/alshedivat/al-folio)**
theme (a popular academic portfolio theme).

- Site URL: `https://jackjameswillis.github.io`
- Source branch: `main`
- Published branch: `gh-pages` (generated by the build/deploy process)

## Environment / stack

- **Jekyll** (Ruby) is the static site generator.
- **Python** is used only for the Google Scholar citation updater.
- **Prettier** (with the Shopify liquid plugin) formats Liquid/HTML.
- **Docker** is available via the `Dockerfile` / `docker-compose.yml` for an
  isolated build environment.
- A **devcontainer** (`.devcontainer/devcontainer.json`) is provided for VS Code /
  `devcontainer`; it installs Ruby, ImageMagick, Jupyter, and Prettier.

## Local development

### Prerequisites
- Ruby (see `.ruby-version`) and Bundler, or use the Docker image / devcontainer.

### Build & preview
```bash
bundle install
bundle exec jekyll serve        # dev server at http://localhost:4000
bundle exec jekyll build        # production build into _site/
```

### Formatting
- Prettier runs in CI. Format manually with:
  ```bash
  npm install
  npx prettier --write .
  ```
- Prettier config lives in `.prettierrc`; Liquid files are formatted by
  `@shopify/prettier-plugin-liquid`.

## Where things live

| Area | Path | Purpose |
|------|------|---------|
| Site settings (title, description, nav, etc.) | `_config.yml` | Edit here for most site-wide changes |
| Pages (about, blog, 404, ...) | `_pages/` | Markdown pages |
| Blog posts | `_posts/` | Dated Markdown posts (`YYYY-MM-title.md`) |
| CV, coauthors, citations, repositories | `_data/` | Structured data (YAML) |
| Publications / citation cache | `_data/citations.yml` | Auto-generated (see below) |
| Site-wide HTML snippets | `_includes/` | Layout partials |
| Layouts | `_layouts/` | Jekyll layouts |
| Stylesheets (SCSS) | `_sass/` | Styling |
| Custom Jekyll plugins | `_plugins/` | Local plugins |
| Static assets (images, libs) | `assets/` | Do not commit `assets/libs/` (gitignored) |

## Google Scholar citations (auto-updated)

`_data/citations.yml` is **not** edited by hand. It is refreshed automatically by a
GitHub Action that runs `bin/update_scholar_citations.py` (using the `scholarly`
library) on Mon/Wed/Fri and on demand.

- The script reads your `scholar_userid` from `_data/socials.yml`.
- On change it commits `Update Google Scholar citations` and pushes to `main`.
- To run locally: `pip install -r requirements.txt && python bin/update_scholar_citations.py`.

## Deploying

The site is published to `gh-pages` by the `deploy.yml` workflow on push to `main`.
There is also a manual deploy helper at `bin/deploy` which builds, purges unused CSS,
and force-pushes to `gh-pages` (it prompts for confirmation and refuses to run with
uncommitted/untracked files).

## Conventions & gotchas

- **Do not hand-edit `_data/citations.yml`** — it will be overwritten by the action.
- Keep `_config.yml` as the single source of truth for site metadata.
- `Gemfile.lock` is committed; run `bundle install` and commit lock updates when
  changing gems.
- `assets/libs/` and `node_modules/` are gitignored.
- The repo contains a large photo (`IMG_3312.JPG`, ~570 KB); keep asset sizes reasonable.
